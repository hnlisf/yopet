# Windows 桌面陪伴第一版

鱼缸顶部显示器图标进入。仅 Windows 支持，网页不显示入口。
主显示器覆盖、置顶、鼠标穿透、隐藏鱼名/水体/布景/操作栏。
返回：Ctrl+Alt+Y 或托盘双击；托盘右键可返回或退出。
托盘或快捷键注册失败时拒绝进入并保留普通鱼缸。
退出恢复窗口样式和位置，不改鱼数据；沿用性格运动和邻鱼避让。

透明实现现已改为透明 RepaintBoundary 捕获、预乘 BGRA 转换，以及独立
Windows 分层窗口 UpdateLayeredWindow/ULW_ALPHA 合成，不再绘制紫色底。
原 Flutter 窗口保持渲染但整体隐藏，每条鱼独立透明窗口鼠标穿透；
仅捕获鱼的局部区域，33ms 定时尝试更新（目标约 30fps，不保证实际帧率），
传帧忙时不排队。高分辨率截图与通道传送仍可能占用 CPU/内存带宽，
需要实机视觉和性能验收；尚未确认所有显卡驱动下的透明效果。
未实现多屏、开机启动、屏保闲置触发或 Explorer
重启后的托盘重建。快捷键在陪伴模式期间有效，退出时注销。

用户已确认本机透明杂边消除、游动流畅，Debug 连续 60 分钟暂未复现冻结。
Release 仍需按 [稳定性验收清单](windows-release-acceptance.md) 单独测试。

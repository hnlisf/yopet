```powershell
.\package-windows-installer.ps1 -Bundle .\artifacts\yopet-windows-local-20261026-132011-657.zip
```

脚本校验原便携包 SHA256 与 checksRun，使用其完整 Release 内容生成安装程序，
不重新编译应用、不执行安装、不发布。产物及校验清单位于 artifacts。
编译器不在默认目录时传入 -IsccPath。暂存目录保留供检查。

## 安装行为

- 仅当前用户，默认 `%LOCALAPPDATA%\Programs\YopetLocal`，不请求管理员权限。
- 开始菜单入口，可选桌面快捷方式，无开机自启。
- 同一 AppId 支持覆盖升级；更新文件被占用时提示关闭应用。
- Windows 卸载入口删除安装文件与快捷方式，不额外清理用户数据或 Docker。
- 仍需要本机 Docker 后端，未签名，非面向公众的生产安装包。

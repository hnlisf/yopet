# Windows Release 稳定性验收

更新：2026-10-25。用于本地测试包，不代表正式发布。

## 已有证据

- 用户确认 Debug 桌面陪伴连续运行 60 分钟，暂未再次出现冻结。
- 这不能代替 Release 实机验收，也不能证明偶发冻结已彻底消除。
- Release 构建不读取仅供调试的 `debugNeedsPaint`；临时诊断计数只在 Debug 启用。

## Release 人工验收（均待测试）

1. 解压完整 ZIP，运行其中的 yopet.exe；本机 Docker / Supabase 保持运行。
2. 确认鱼缸加载，进入桌面陪伴，观察鱼鳍、移动及透明边缘。
3. 连续运行至少 90 分钟，期间正常使用其他应用；记录开始和结束时间。
4. 锁屏后解锁三次，检查鱼是否立即继续游动。
5. 鱼缸与桌面陪伴切换十次，检查没有残留鱼窗口或重复鱼。
6. 验证 Ctrl+Alt+Y 和托盘返回鱼缸；重新进入陪伴后继续游动。
7. 验证鼠标停留互动、托盘“陪我一会儿”、桌面点击穿透。
8. 退出并重开，确认账号与鱼缸数据仍正常。

若再次冻结，先记录时间、是否所有鱼和鱼鳍同时停止，以及快捷键是否有效，
再返回鱼缸，记录是否恢复。不要将返回后恢复视作本轮验收通过。

本地包连接本机后端，非独立离线应用；暂不包含签名、安装器或生产服务配置。

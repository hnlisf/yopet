## 兼容与回滚

客户端继续写合法旧配对，由服务端同步编号；读取优先使用编号。
旧单特征或冲突组合不可新增，但既有旧鱼的非性格更新不受影响。
若需回滚，先停止写入并按备份恢复或演练后的逆向迁移处理；不要直接删除
traits 兼容列，不要自动覆盖无法精确映射的旧鱼。
当前没有对真实测试鱼缸执行上述应用步骤。

客户端后续收尾：领养预设鱼、保存自定义鱼、调整性格均显式写入
personality_code 与兼容 traits；仅允许四个命名组合。读取以编号优先。

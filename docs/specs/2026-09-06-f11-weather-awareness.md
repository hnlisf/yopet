# F11 — 真实天气影响鱼缸氛围

## Outcome

玩家主动搜索并选择一座城市。yopet 使用无需 API key 的 Open-Meteo
geocoding 与 forecast endpoint，读取该城市此刻的温度、WMO 天气码与昼夜状态，
并把最近成功读取的完整快照保存到玩家自己的鱼缸。应用不会请求精确设备定位。

天气只在氛围层生效：它改变鱼缸的柔和光线、水面纹理，以及自由游动的节奏。
晴朗时略活跃；多云、薄雾、细雨、雨、雪与雷雨时略慢。它不造成疾病、死亡、
倒计时、警报或必须完成的照料任务，符合 ADR-0001。

## Flow

1. 首页顶部天气状态按钮打开「天气氛围」面板。
2. 玩家可先点晴朗、少云、多云、薄雾、细雨、雨天、雪天、雷雨任一按钮，在不
   保存数据的前提下即时预览鱼缸光效与游速。
3. 玩家输入城市名并选择搜索结果后，客户端读取该城市的当前天气，完整保存到
   `tanks`，通过既有 realtime stream 同步所有已登录设备。
4. 网络暂时不可用时，保留最后一次成功快照；从未设置过城市时保持默认静谧水光。

## Data contract

`tanks` 增加 `weather_city_name`、经纬度、`weather_code`、
`weather_temperature_c`、`weather_is_day` 与 `weather_observed_at`。数据库约束
保证这些字段要么全部为空、要么构成一个完整快照。所有字段仍受既有「仅本人可读
写自己的鱼缸」RLS 规则保护。

## Verification

- Dart tests覆盖 WMO 到氛围映射、所有状态的非惩罚性游速范围、Open-Meteo 城市与
  天气响应解析，以及保存载荷。
- SQL acceptance test 覆盖拥有者保存完整快照、拒绝部分快照与 tanks RLS。
- 手动预览：在首页点顶部天气按钮，逐个点预览天气；再搜索城市并选择一个结果，
  确认顶部状态和鱼缸氛围随之更新。

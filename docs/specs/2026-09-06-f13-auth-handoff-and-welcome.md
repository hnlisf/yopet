# F13 · 账号进入与欢迎页

## 修复

登录请求成功后，Supabase SDK 会立刻持有 session，但认证事件流可能稍后才发出事件。路由此前只读取事件流，导致用户已经登录成功却仍停留在登录页。

`currentUserProvider` 会在这段短暂交接期回退到 SDK 当前用户；更关键的是，路由本身直接读取 SDK 当前用户，而不读取可能还没重新计算的 Provider 缓存。对应回归测试覆盖“SDK 已有 session、事件流尚未到达”的状态和进入鱼缸的路由决策。

注册流程也会明确处理没有返回 session 的情况：账号创建后要求完成邮箱确认，而不会错误地跳转到一个仍未认证的鱼缸页。

## 视觉

- 登录和注册共享鱼缸的深色水彩背景、既有金鱼 sprite 与青色水光。
- 表单改为底部水面 sheet，提供密码显隐、清晰错误状态和同步说明。
- 鱼使用圆润、轻松的项目既有水彩风，而非写实鱼类插画。

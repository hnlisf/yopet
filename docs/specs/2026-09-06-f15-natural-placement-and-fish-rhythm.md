# F15 — 自然摆放与自由游动

> Status: implementation and verification
> Extends: F14 decoration composition and the existing tank scene

## Outcome

布景编辑不再留下“还在编辑中”的悬置状态：选中物品后，用户可以点击勾选完成、再次点击该物品完成，或点击鱼缸空白处完成。拖动仍会即时保存位置，缩放仍沿用 F14 的持久化范围。

根系小屋使用独立的透明水彩素材，保留原始素材文件。通用布景图层不再给所有物品强制叠加颜色混合，因此透明边缘、底部轮廓和各物品本来的水彩色彩能与深色鱼缸背景自然融合。标准化 `position_y = 1` 表示物品的底边贴齐缸底。

每条鱼根据其稳定 ID 获得独立的游动档案：不同的初始出发延迟、路线随机种子、0.88–1.12 的节奏系数，以及三种平缓转向曲线。天气、水温、饱食度和性格仍共同影响游动；新档案只移除“所有鱼同时出发、同时转向”的机械感。

## Interaction contract

- 点击物品：选中并显示缩放、完成、移出控制。
- 再点同一物品、点勾选、或点鱼缸空白处：完成摆放并收起控制。
- 拖到最下方：可以持久化 `position_y = 1`，视觉底边贴齐缸底。
- 不同鱼的游动既可重复辨认，也会错峰开始和以不同节奏巡游。

## Verification

- 小部件测试覆盖再次点击确认、点击空白处确认、贴底拖动及缩放边界。
- 单元测试断言不同鱼 ID 获得不同的出发延迟、路线种子和游动节奏。
- 完整 Flutter 测试：38 passed；静态分析：no issues。
- Web release preview 已构建，并在已登录的鱼缸数据下检查透明根木、缸底摆放与编辑工具栏。

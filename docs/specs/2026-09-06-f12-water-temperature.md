# F12 · 手动水温

## 交付内容

- 每个鱼缸保存一个 `18–30°C` 的手动水温，默认 `24°C`。
- 鱼缸顶部可直接打开水温面板；滑杆、加减按钮和保存动作都适合触屏操作。
- 面板按鱼种偏好温度显示「舒适 / 稍凉 / 稍暖 / 偏凉 / 偏暖」的轻量提示。
- 水温只轻微改变自由游动的节奏；不会扣除饱腹、阻止成长、制造疾病或推送焦虑提醒。

## 数据与权限

`tanks.water_temperature_c` 由 F12 migration 添加，并受既有的鱼缸 owner RLS 与 Realtime 保护。数据库约束拒绝 `18–30°C` 以外的值。

## 验收

运行 `supabase/tests/f12_water_temperature.sql`：验证默认值、owner 保存、范围约束与 RLS 保持有效。Flutter 单测验证偏好范围和温和的游动倍率。

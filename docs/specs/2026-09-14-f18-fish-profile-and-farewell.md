# F18 · 鱼档案与温柔送别

日期：2026-09-14
状态：本机实现及数据库验收完成，等待人工体验确认

2026-10-05：用户确认鱼档案流程没有问题。送别删除流程未收到单独人工确认，
仍保留为可选人工验收项；不自动删除用户现有鱼。

## 用户目标

1. 点开一条鱼时，可以认出它的鱼种或自定义外观、成长阶段、陪伴天数与性格，而不只是看到饱腹度。
2. 鱼缸达到 5 条容量后，用户可以释放一个名额，继续体验其他预设鱼或组合式自定义鱼。

## 交付范围

- 鱼详情以同一条水彩鱼的缩略图开场，并展示鱼种与变体；自定义鱼展示体型、尾鳍和纹样组合。
- 性格以轻量标签展示。大胆、害羞、好奇和慵懒仍由 F8 的真实游动行为表达，标签只帮助用户理解。
- 展示成长阶段和“来到鱼缸第 N 天”，不制造倒计时或催促。
- 详情底部提供“让它去新的水域”。必须经过带鱼名的二次确认才会删除；取消不会发生任何变化。
- 删除沿用 F6 已有的 owner-only RLS，投喂与成长日志通过外键级联清理。应用不允许删除别人的鱼。

## 边界

- 不做鱼死亡、生病、出售或货币补偿。
- 不自动替用户送别任何鱼，测试也不删除现有账号中的真实数据。
- 本阶段不增加多鱼缸，也不改变 1–5 条容量规则。

## 验收

- Widget 测试验证预设鱼与自定义鱼的档案文案、性格标签、送别取消、二次确认和失败重试。
- 既有鱼种、自定义鱼、成长、投喂、天气、水温与装饰测试继续通过。
- 完整 Web 项目构建后提供本机预览，由用户在自己的鱼缸中手动确认档案；送别操作仅在用户主动确认后执行。

# F16 — 可见贴底与鱼群节奏

> Status: implementation and verification
> Corrects: F15 visual placement and swim-rhythm feedback

## Findings

真实测试鱼缸中，`driftwood.position_y` 已保存为 `0.999`，但仍在缸底上方可见悬空。问题不在持久化：源 PNG 的水彩主体下方有 72px 透明留白，旧图层把 PNG 画布而不是可见轮廓贴到缸底。

F15 的逐鱼哈希能产生不同的数值，但真实三条鱼的首次移动只相差约 0.7–1.6 秒、节奏差最大 14%，不构成用户肉眼可感知的差异。

## Outcome

- 每个预设布景都有根据透明画布测得的 `contentBottomInset`。规范化
  `position_y = 1` 现在锚定可见水彩轮廓的底边；图片不可见的留白可以超出
  鱼缸裁切区域。
- 鱼缸按稳定的创建顺序为鱼分配三种循环角色：慢游、巡航、探索。它们分别在
  大约 0.5、3、5.5 秒后起游，并使用 0.78、0.98、1.16 的节奏系数、不同缓动曲线
  与不同巡游区域。天气、水温、饱腹度和性格的既有影响仍会叠加。

## Verification

- 回归测试验证沉木在 `position_y = 1` 时，透明留白补偿后的可见底边抵达缸底。
- 回归测试验证相邻鱼缸槽位在启动阶段、节奏、巡游角色与区域上均有明确差异。
- 全量 Flutter 测试：39 passed；静态分析：no issues。
- 已在当前已登录的本地浏览器预览中复核：沉木贴底、鱼群错峰游动、无控制台错误。

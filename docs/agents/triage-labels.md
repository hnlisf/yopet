# Triage 标签

各技能按 5 种 canonical triage 角色沟通。本文件把角色映射到本仓库 issue tracker 实际用的 label 字符串。

| mattpocock/skills 中的角色 | 本仓库 tracker 中的 label | 含义 |
| -------------------------- | ------------------------ | ---- |
| `needs-triage`             | `needs-triage`           | 维护者需要评估这个 issue |
| `needs-info`               | `needs-info`             | 等报告人补充信息 |
| `ready-for-agent`          | `ready-for-agent`        | 描述完整,可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`        | 需要人工实现 |
| `wontfix`                  | `wontfix`                | 不会处理 |

技能提到某个角色时(比如"打上 AFK-ready triage 标签"),用本表里对应的 label 字符串。

把右栏改成你实际用的词汇即可。

# ADR-0001 — 无惩罚原则(鱼永不生病、不会死)

yopet 的产品初衷是为城市白领用户提供低压力的情绪陪伴。因此我们承诺把每一个会改变状态的系统——天气、喂食节奏、水温——都放在氛围层(mood layer)上:它们的作用只是调节活跃度、表现和氛围,绝不引发疾病、饥饿伤害或死亡。这是对真实水族箱模拟的刻意偏离;未来的工程师看到没有血条,自然会以为这是没做完。其实不是。

**后果**:不存在失败状态、游戏结束、恢复动作。鱼离开鱼缸的唯一方式是玩家选择放生或替换。任何引入"伤害状态"的 feature 提案必须驳回,或者把范围限制成非致命信号(比如久不互动 → 表情更忧伤,但绝不是疾病)。

# ADR-0005 — 鱼只对"当前状态"做反应,不做历史记忆

yopet 的鱼识别玩家的**当前**在场(点击、从后台返回),用一段简短的问候或性格化反应来响应,但不记忆过去发生的事。这是 MVP 范围内刻意画的边界:产品"精神陪伴"的目标,来自"一条鱼注意到你"的氛围感,而不是来自"积累历史的鱼"。以后再加历史记忆(命名周年 / 首次喂食 纪念日、"你想你的鱼了")需要新建一张 fish_events 表、一个跑纪念日的调度器、以及读取这张表的行为树——是一次重大的改造。

**后果**:任何需要记忆的 feature(周年反应、"你的鱼想你了"、"记住喜欢的食物"),要么在设计阶段驳回,要么推迟到 v2,要么通过别的途径表达。如果陪伴的丰富度成了留存的瓶颈,这条边界就是该重新审视的地方。

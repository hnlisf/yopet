# yopet — UI 设计

> 状态: v0.1(初版设计计划)
> 作者: hnlisf + Claude
> 最近更新: 2026-08-03

## 1. 设计方向(一段话)

**夜间水族箱。** 玩家打开 yopet,鱼缸是唯一光源——周围一切都是暗的,水从内部柔和发光,鱼本身是屏幕上最亮的东西。氛围是亲密、冥想式的:一个可以合上标签页、走进去待五分钟的私密小世界。这刻意拒绝了品类里"明亮的蓝色水族箱"默认;大多数水族 App 把鱼画在欢快的白昼背景上,对城市白领玩家来说形态不对——他们是来减压的,不是来被"欢快"的。

## 2. 主题、用户、唯一任务

- **主题** — 桌面 + 移动端养鱼游戏,玩家在单个鱼缸里领养 1–5 条命名鱼、装饰缸、看它们长大、感受它们的存在。完整规格见 `PRD.md`。
- **用户** — 城市白领(25–45),屏幕疲劳,想要 5 分钟平静仪式,对惩罚循环耐心低。喝咖啡时、睡前、开完会后玩。
- **首页的唯一任务** — 把玩家的鱼展示在鱼缸里。其他一切都为它服务。

## 3. 调色板

六个命名 token。Hex 是真理之源;语义名说明它的角色。

| Token | Hex | 角色 |
|---|---|---|
| `--yopet-bg` | `#0E1620` | 页面背景——近黑、稍蓝。"暗下来的房间"。 |
| `--yopet-surface` | `#1A2733` | 卡片 / sheet / drawer 表面——比 bg 高一层。 |
| `--yopet-tank-glow` | `#5BA8B5` | 水光、鱼 sprite 染色、主 accent。柔和青绿,低饱和。 |
| `--yopet-tank-glow-soft` | `#7FBFC9` | tank-glow 元素的 hover / focus。 |
| `--yopet-plant` | `#7E9B7E` | 装饰水草、success / 存活状态。柔和鼠尾草绿。 |
| `--yopet-amber` | `#D4A574` | 水温暖感、食物、"需要关注"(不警报)。绝不红。 |
| `--yopet-text` | `#E8EEF2` | 主文本——柔白,绝不纯 `#FFF`。 |
| `--yopet-text-dim` | `#8A9BA8` | 次文本、字幕、元信息。 |

**不要纯黑**(用 `#0E1620` 替代——太临床),**不要纯白**(用 `#E8EEF2`),**不要饱和红**(错误用降饱和的 amber)。整个调色板处于暗与冷之间;唯一的暖色是 `--yopet-amber`。

## 4. 字体

| 角色 | 字族 | 字重 / 字号 | 为何选它 |
|---|---|---|---|
| **Display** | **Fraunces**(Google Fonts,可变)| 500–600,克制使用 | 半衬线,曲线柔和、有机感,有点俏皮但不卖萌。可变轴允许按场景调光学尺寸。仅用于:App logo "yopet"、屏标题、鱼名(详情卡)。 |
| **Body / UI** | **Manrope**(Google Fonts)| 400 / 500 / 600 | 几何无衬线,比例友好,微圆——14–16sp 时清晰可读,不与 Fraunces 抢戏。 |
| **Numeric** | **Manrope** tabular figures | 600 | 水温、饱腹度百分比、计时器。 |

**刻意配对**:Fraunces + Manrope。两者都有一点暖意(Fraunces 的有机曲线、Manrope 的圆头末端),但看起来不像标准的"衬线 + Inter"。避免:Playfair + Inter、Lora + Inter、EB Garamond + 任何。

**字号阶梯**(基础 16sp):

```
display-xl    Fraunces 600   32sp   屏标题、空状态标题
display-lg    Fraunces 500   24sp   详情卡里的鱼名
heading       Manrope 600    18sp   段落标题
body          Manrope 400    15sp   正文
caption       Manrope 500    12sp   元信息、标签
micro         Manrope 500    10sp   时间戳、徽章
```

**间距**:4px 基本单位。卡片内边距 16px。节段之间纵向节奏 24px。

## 5. 签名元素

**鱼 sprite 发光。** 每条鱼的 sprite 都带一层细微的内辉——鱼身周围 4–6px 的柔和青色 halo(`--yopet-tank-glow` 30% alpha + 高斯模糊)。鱼成为屏幕上最亮的像素群,像一条暗水里的发光生物。鱼动,光晕跟着。鱼在"活跃"时(响应玩家),光晕会微微脉冲。

这是 yopet 一张截图就能让人认出来的元素。它也承载了美学风险:它把我们绑在暗色画布方向(glow 在亮背景上看不出来),并且约束鱼 sprite 的画法(亮核 + 暗描边,反过来不行)。

│                                                    │

认证页是进入鱼缸前的一段安静仪式：深色水彩鱼缸背景延续主屏的水草、气泡和暗水质感；顶部为 Fraunces `yopet` 字标和一句轻量欢迎语；一条与鱼缸内完全相同的、圆润水彩金鱼在欢迎区和表单之间游过。底部表单像浮在水面上的半透明 sheet，包含登录 / 注册切换、邮箱、密码、主操作和“同一账号会带着你的鱼缸一起回来”的同步说明。

### 6.5 装饰抽屉

从右侧滑入,移动端 ~75% 宽 / 桌面固定 360px。顶部:标题"装饰" + 关闭 X。主体:装饰 tile 网格(每个 tile 是正方形缩略图 + 标签)。把 tile 拖到缸里放置;点已放置的装饰移除。**没有"购买"或"货币" UI**——MVP 所有装饰免费。

## 8. 动效原则

- **鱼的运动**:正弦前进速度 + Perlin 噪声游走。速度 30–80 px/s。每 4–8 秒随机改方向。
- **装饰**:静止,不动。它们没有生命。
- **水面**:每屏顶部细 2px 线,微妙的 3 关键帧正弦波纹,4 秒循环。
- **气泡**:8–12 颗粒,60–100 秒向上漂,在端点淡入淡出。
- **屏切换**:250 ms 交叉淡入。无滑入面板(drawer / sheet 除外)。
- **互动时鱼 glow 脉冲**:glow alpha 30% → 60% → 30% over 1.5s,点击触发。
- **Reduced motion**(`prefers-reduced-motion` / Flutter `MediaQuery.disableAnimations`):杀掉波纹、气泡、glow 脉冲;鱼保留运动但速度减半。

## 9. 文案 register

对话式、Sentence case、具体。像朋友写的。

| 场景 | 文案 |
|---|---|
| 空鱼缸 | "还没有鱼。从下面选一只开始?" |
| 登录 CTA | "登录" |
| 注册 CTA | "注册" |
| 喂食动作 | "喂食" |
| 装饰 | "装饰" |
| 确认领养 | "确认放入鱼缸" |
| 缸满(5/5) | "缸里已经有 5 只了。放走一只再加新的。" |
| 问候(回来)| (无文本 —— 仅动画) |
| 错误 | "找不到你的鱼缸。检查网络,刷新试试。" |
| 离线 | "没有网络,但你的鱼还在等。打开应用照常看它们。" |
| 饱腹度低 | "小鱼有点饿了。"(在鱼详情卡里,amber 色) |

**语气规则**:

- 主动语态、第二人称("你的鱼" 而非 "用户的鱼")
- 绝不 "Click here"、"Submit"、"OK" —— 总是动词开头
- 错误告知发生了什么 + 怎么修
- 无感叹号
- 正文无 emoji(emoji 只作为按钮图标或鱼缩略图)

## 10. 美学风险,以及为什么值得承担

**走暗色。** 水族 / 宠物 App 的标准做法是白昼、欢快调色、插画场景。我反其道而行之——暗色画布、glow 点缀的鱼、柔青绿光。这是真实的风险:

- **为什么可能失败**:在亮环境下,暗 UI 让部分用户疲劳;低端安卓上的 glow 效果会掉帧;签名(鱼 glow)约束了美术方向。
- **为什么我还是要承担**:用户群(城市白领、屏幕疲劳、平静仪式)和价值主张(氛围陪伴,不是欢快分心)是定死的。明亮的鱼缸美学对抗这份 brief。暗色方向服务它——打开 yopet,世界暗下来,你可以安静地看你的鱼。
- **签名让风险具体化**:鱼 glow 是那个一锤定音的元素——如果我们做对了,会让 yopet 在 App Store 里跟别人都不一样。

## 11. 开放的设计问题(推迟)

- **声音设计** —— 环境水声?默认开?按 PRD §10 推迟到 v2
- **亮色主题** —— 是否做一个白天的变体给无障碍用户?还是只承诺暗色?推迟
- **App icon** —— 需要同方向(暗 + glow)的定制插画。不在本文件范围。
- **鱼 sprite 流水线** —— 手绘 vs AI 辅助(按 PRD,两者都可);本设计假定**美术方向已定**(亮鱼 + 暗水 + glow),不关心来源

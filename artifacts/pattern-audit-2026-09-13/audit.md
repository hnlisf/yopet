# 自定义鱼纹样审查 — 2026-09-13

## 1. 梭形体型 / 扇形尾 / 虎纹

健康度：需修复（修复前截图：`01-torpedo-fan-tiger.png`）。

- 虎纹呈低饱和灰褐色，且带纹的顶部和底部过齐，视觉上像 UI 柱形。
- 新规则：暖深褐色、略带弯曲和宽窄变化的纵向色带，仅绘制在鱼身核心区。

## 2. 梭形体型 / 扇形尾 / 双色腹

健康度：需修复（修复前截图：`02-torpedo-fan-belly.png`）。

- 双色腹使用了直线轮廓，形成矩形色块。
- 新规则：乳白暖色的下腹弧面，以三段贝塞尔曲线收束，不延伸到胸鳍或尾鳍。

## 3. 菱形体型 / 扇形尾 / 鞍斑

健康度：需修复（修复前截图：`03-diamond-fan-saddle.png`）。

- 旧鞍斑从纹样区域顶部开始，而该区域与背鳍重叠，出现背鳍染色。
- 新规则：三枚红棕色圆润鞍斑从鱼身上半部开始；菱形体型的色素核心区从画布高度 0.41 才开始，避开背鳍。

## 4. 圆润体型 / 扇形尾 / 双色腹

健康度：需修复（修复前截图：`04-round-fan-belly.png`）。

- 旧颜色分区有硬直边，且靠近胸鳍。
- 新规则：将圆润体型的可着色鱼身核心收至高度 0.40–0.61，并使用连续下腹弧面。

## 限制

- 审查基于用户提供的修复前界面截图。
- 新实现已通过纹样策略回归测试、界面测试、静态分析和本地网页构建；仍需人工切换全部八种纹样与八种体型，确认艺术感符合预期。
